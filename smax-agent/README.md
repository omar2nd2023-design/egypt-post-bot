# وكيل بوابة SMAX — المرحلة 1

نبض وحالة **فقط**. مافيش متصفح ولا Playwright ولا دخول على SMAX ولا
طابور مهام. الغرض إثبات السلسلة:

    الجهاز  --HTTPS صادر-->  Worker  -->  agent_state

**التتبّع العادي مالوش أي علاقة بالوكيل ده.** لو الوكيل مقفول،
التتبّع بيشتغل زي ما هو بالحرف.

## الإعداد

    copy agent.example.env agent.env
    # املا AGENT_SECRET

`agent.env` و`agent_id.txt` و`agent.log` **مايدخلوش git**.

## التشغيل

    python agent.py

للتشغيل من غير نافذة سوداء:

    pythonw agent.py

## الإيقاف

`Ctrl+C`، أو إنهاء العملية. الوكيل بيمسك `SIGINT`/`SIGTERM` وبيقفل نضيف.

## معرفة الحالة

    curl -H "Authorization: Bearer <ADMIN_SECRET>" https://<worker>/agent/status

    🟢 ONLINE                  نبضة حديثة + SMAX جاهزة
    🟡 ONLINE_SMAX_NOT_READY   نبضة حديثة + SMAX مش جاهزة  ← المرحلة 1 دايمًا هنا
    🔴 OFFLINE                 آخر نبضة أقدم من 90 ثانية

**الـWorker هو مصدر الحقيقة** — الوكيل بيبعت حقائق بس، والقرار هناك.
منطقي: لو الوكيل مقفول مش هيقدر يقول عن نفسه إنه مقفول.

## الإيقاع

    نشاط حديث   → كل 5 ثواني
    سكون        → كل 20 ثانية      (المرحلة 1 دايمًا هنا)

20 ثانية = ~4,320 طلب/يوم = **4% من حد Cloudflare المجاني**.

## معرّف الوكيل

بيتولّد مرة واحدة ويتخزّن في `agent_id.txt`. **إعادة التشغيل بتستخدم
نفس المعرّف** — فمافيش صفوف مكررة.

## ليه Turso مش KV

KV المجاني = **1000 كتابة/يوم**. نبضة كل 20 ثانية = 4,320 كتابة —
تكسر الحد وتعطّل تخزين التوكن نفسه. وكمان KV اتساقه مؤجّل.
